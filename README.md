# NTPU HomeworkInOne Dark · v0.4.0

這是獨立開發的本機 Moodle 作業工作台。登入後可同步課程與作業，選擇題目和附件，用 NTPU AI 產生草稿，再審閱並匯出 PDF、Word 或 ZIP。

## 安裝

請準備 Windows x64、Python 3.12、uv、Node.js 20.9 以上、Git，以及 Chrome 或 Edge。

第一次安裝或更新依賴時，在專案根目錄開啟 PowerShell，執行下列指令。腳本會準備 Python 套件、Node AI Bridge 和中文字型。

```powershell
./scripts/setup_dev.ps1
```

## 開啟使用

在專案根目錄的 PowerShell 執行下列指令，再用瀏覽器開啟終端機顯示的 `http://127.0.0.1:8766/unlock/...` 網址。

```powershell
./scripts/run.ps1
```

1. 開啟右上角的 **連線管理**，選擇 **Moodle** 並以本人帳號登入。
2. 到 **我的課程** 開啟課程，按 **完整同步本課** 取得作業、教材、公告和評分。要一次同步多門課，請到 **學習資料** 勾選課程，再按 **同步選定課程**。
3. 要使用 AI 時，在 **連線管理** 選擇 **NTPU AI**，按 **開啟 NTPU AI 登入視窗**。登入後關閉專用視窗，再按 **恢復所選連線**。
4. 從首頁的作業清單或 **作業工作台** 選擇課程和作業。

## 處理作業

### 一步一步完成

1. 選擇 **一步一步完成**，按 **下一步：確認資料**。閱讀題目，勾選需要的附件，再按 **下載並讀取資料**。若 Moodle 沒回傳題目文字，可到 Moodle 原頁確認後貼到工作台。
2. 核對讀取的題目與節錄。想指定摘要、解題規劃、報告草稿或程式解題，可展開 **補充設定**。支援 PDF、DOCX、TXT、CSV 和 PNG／JPEG／WebP 圖片。掃描 PDF 與圖片可做本機 OCR，請核對辨識內容。若要把選定附件的圖表或公式影像送給 AI，請在 **補充設定** 勾選影像傳送。
3. 核准本次傳送後按 **開始執行**。需要查文獻時，可先在 **補充設定 → 公開文獻查詢** 填寫主題或 DOI，選擇 Crossref、Europe PMC 或兩者，再確認要送出的查詢。取得的文獻可在審閱頁查看。

### 直接完成作業

選好作業後切換為 **直接完成**，按 **開始直接完成**，確認題目、附件傳送和執行範圍。系統會讀題、分析資料並產生草稿，視作業需要取得公開資料集或在 Docker Runner 執行 Python。報告依題目指定語言撰寫，未指定時使用繁體中文。

若缺少資料、部分附件無法讀取或實驗尚未執行，草稿會保留已完成內容，並在 **使用者待辦** 列出要補做的事項。匯出後請自行到 Moodle 繳交。

### 審閱與輸出

1. 在 **審閱與輸出** 核對草稿、來源和待處理事項。可展開 **編輯草稿** 修改，修改後請重新確認審閱。
2. 選擇 **匯出 PDF**，或在 **其他格式** 匯出 Word／ZIP。PDF 的 7 至 12 欄表格會改用橫頁，超過 12 欄會分組並保留首欄。跨頁會重複欄名。
3. 要一併保留題目和選定參考檔，匯出 ZIP 前勾選 **ZIP 也包含原始題目與附件**。若 PDF 匯出失敗，可以下載 Markdown、已產生的程式碼，或改用其他可用格式。

## 準備程式執行環境（Docker）

**沒有 Docker**，照上方步驟安裝主程式並用 `./scripts/run.ps1` 啟動即可。可同步作業、讀取附件、產生草稿、做基本 CSV 統計和匯出。遇到需要執行程式的作業，會保留產生的程式碼，並把尚未執行的實驗列為待辦。

**要讓系統實際執行 AI 產生的 Python 或跑實驗**，先完成 `setup_dev.ps1` 的主程式安裝，再準備 Docker Runner。Runner 會在隔離容器內執行 Python，環境提供 Python 標準函式庫。

1. 安裝並啟動 Docker Desktop，使用 WSL 2 後端和 **Linux containers**。
2. 在專案根目錄執行下列指令，建立並檢查 Runner。

   ```powershell
   .venv/Scripts/python.exe scripts/setup_runner.py
   ```

3. 看到 `Runner ready` 後，用 `./scripts/run.ps1` 啟動主程式。執行程式期間保持 Docker 引擎運作。平常可沿用已建立的 Runner，變更 Runner 或重裝 Docker 後再重新建置。

若 Docker Desktop 顯示 `docker_engine` 存取被拒，而 Podman 同時運作，請先確認 Podman 沒有執行中的工作，再停止 Podman machine 並重新啟動 Docker Desktop。

## 學習資料與搜尋

- 在 **連線管理** 以與 Moodle 相同的本人帳號登入校務系統，再到 **學習資料** 同步正式課表、歷年成績、排名與畢業進度。
- 在 **學習資料** 可選目前修課或指定學期（例如 `115-1`），勾選課程同步。下載教材時需逐份核准。
- 右上角的 **搜尋課程與文件** 可找課程、作業和已下載的教材。

## 繼續任務與管理本機資料

- 任務中斷時可按 **從中斷點繼續**。若登入失效，先恢復連線再續跑。畫面若提示 **重新執行**，舊草稿仍可在 **歷史任務** 找到。
- 附件、草稿和快取保存在本機。若要清除資料，在 **連線管理 → 本機資料與診斷** 先預覽清除範圍，再確認清除目前帳號資料。
