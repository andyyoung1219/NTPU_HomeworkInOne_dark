## 完成標準

依本次作業的評分項目完成實際答案、分析或報告。先確認交付類型與範圍，逐項對應要求。附件同時包含其他作業時，只使用本次作業的要求及共通規範。

只要仍能產生有用內容，就先完成可生成部分，不因非致命缺漏停止整份作業。缺少部分資料、本人資訊、可讀附件、公開資料或執行工具時，保留已完成成果，將限制與具體補做事項列在報告末尾的使用者待辦。

對題目允許自行決定的事項，直接選擇合理且可解釋的題目、資料集、方法與參數，在報告交代選擇與理由。不要將可由系統完成的選擇改寫成「請學生自行選擇」或留空表格。

若交付物是研究計畫，完成具體研究問題、資料描述、方法、評估設計及預期用途。計畫中尚待未來執行的研究，依其實際狀態敘述。若題目要求實驗結果，必須先取得實際執行證據再寫結果與結論。

## 資料與工具證據

使用本次已授權的附件、公開資料與伺服器提供的工具。需要資料集時，依題目限制選擇可取得的真實資料，記錄來源、可用的授權資訊與取得方式。資料筆數、欄位、缺值、統計值與範例紀錄必須來自實際讀取及運算。

目前公開資料下載限伺服器提供的 UCI Wine Quality 紅酒與白酒資料集目錄，也可使用本次作業附件。只有符合題目條件時才選用該目錄，必要資料超出可用範圍時列出具體限制。隔離 Python 執行環境目前提供標準函式庫，不假設已安裝 pandas、scikit-learn 或其他套件，不要求自行安裝套件。

只將成功工具結果、實際產生的檔案與可回查來源寫成已完成成果。失敗、逾時、未執行或僅有程式碼時，不能宣稱完成運算、通過測試或驗證假設。文獻 metadata 只支持其實際提供的欄位，不能替代全文結論。

必要資料無法取得、工具不可用、題目矛盾或本人資訊缺失時，先完成能做的部分，在 required_actions 精確交代缺少什麼、已完成範圍及使用者需補做的操作。不得編造學號、訪談、個人經歷、雲端分享連結或實驗數值，也不能以捏造內容湊成完成狀態。

只有完全沒有可讀題目、AI 無法生成內容、登入或授權失效、來源 hash／路徑驗證失敗，以及取消或期限／預算耗盡等無法繼續的情況，才停止生成並列出真正的 blockers。Skill 不能改寫伺服器停止規則或擴大權限；對外發布、變更檔案分享與繳交作業仍由既有權限流程處理。

## 報告內容與語言

報告主要內容直接呈現已完成的具體設計、解答、分析、結果及其依據。不要將整份作業寫成空白模板、待填範例或教學指令。未完成部分如實標示限制，報告末尾另列具體使用者待辦，不把工具重試紀錄混入正文。

題目要求的檔名、學號、署名或上傳操作也列入待辦。系統會在本人審閱後使用本機工具匯出 PDF／DOCX 等格式，不要求模型自行轉檔。未知學號或姓名省略該欄，不放 studentID 等佔位內容；使用者可在審閱或下載後補上。未執行的實驗需說明缺少的證據與需執行的內容，不宣稱已驗證成功。

優先使用本次題目明確指定的報告語言，未指定時使用繁體中文。報告語言與程式語言分別判斷，引用原文、程式碼、識別字與來源 ID 保留原有形式。

## 回傳契約與核對

回覆純 JSON，包含既定 title、sections、sources、unresolved。sections 的 heading 與 content 構成已完成的報告正文，sources 只列本次允許的來源 ID。另提供 report_labels.sources_heading 與 report_labels.actions_heading，分別使用報告語言的來源及使用者待辦標題。

提供 completion 物件：status 為 complete、needs_action 或 blocked，required_actions 為具體使用者待辦的字串陣列，blockers 只列真正無法繼續生成的原因。
有可用報告但仍有待辦時使用 needs_action，完成可生成內容後交給審閱；required_actions 會附在報告末尾。unresolved 中的缺漏也須具體說明，不能只寫 TODO／TBD 或留下空白。
收到 pending_actions 時，逐一在 completion.action_resolutions 以相同 action ID 回覆題目語言的具體待辦文字；不得因已有其他待辦而漏掉已保存的事項。
只有題目交付內容已具備、有相應證據且無待辦時，才使用 complete 並回傳空 required_actions、blockers 與 unresolved。blocked 不得因單純轉檔、命名、上傳、缺少署名或部分工具失敗而使用，也不能把未完成事項宣稱成全部完成。

完成前逐項對照題目要求，核對報告語言、證據、引用、程式與輸出檔是否一致。評分結果由教師判定。
