# P1 MVP 驗收

日期：2026-11-02，Windows x64，Python 3.12.14、Node 24.14.0。

## 真實端到端

驗證目標為已授權課程中的一份指定作業。

1. P0 已確認本人 Moodle、真實附件、NTPU AI 登入及內容傳遞。
2. P1 重新同步選定課程，取得四份作業，下載指定作業的一份 PDF。
3. 驗證時記錄來源 PDF 的 SHA-256。
4. 解析 15 頁，提供有 file_id／page 的節錄及可編輯要求清單。
5. 本人核准 P1 本次資料傳送，產生與選定作業相關的繁體中文結構化草稿。
6. 第一次任務回報 AI_BRIDGE_ERROR，保留失敗狀態；本人再次操作後成功，未誤報成功。
7. 本人在工作台審閱並核准匯出，得到 **8 頁 PDF** 與 Markdown/manifest。
8. 驗證時記錄匯出 PDF 的 SHA-256。
9. 自動檢查開啟、文字、空白頁、邊界、中文嵌字通過；已逐頁查看 8 張渲染圖，
   中文、跨頁表格、頁碼無截斷或重疊。PDF 為含 TODO 的驗收草稿，不代表完成實際專案。

真人輸入、模型原文與 PDF 保存在忽略追蹤的 `.local/`，不提交 Git。
另以合成 DOCX 樣本驗證標題、段落、表格，CSV 驗證只傳欄位與前五筆。

## 已知限制

- 真人驗證涵蓋 Windows、一門課、一份作業及一種真實 PDF；其他格式用合成樣本覆蓋。
- 要求抽取為可編輯規則式初稿，可能混入同附件其他作業，需核對。Prompt 明確以選定作業為範圍。
- 複雜公式、圖片、PDF 表格語意與 OCR 不保證，會提示人工核對或需要 OCR。
- 只提供本機單使用者模式，任務依 Moodle 身分分區；不提供公開部署與多租戶。
- 模型回覆須人工審閱；本版未執行程式、研究或實驗，不自動提交作業。
