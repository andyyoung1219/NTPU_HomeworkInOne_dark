# P4 學習中心 v0.4.0

更新：2026-11-04。本次依使用者選擇實作 1、3、4、7、8；不是原始 spec 的全部 P4 選項。

## 已實作與使用方式

1. 首頁「學習總覽」顯示今日課程、七日內截止、逾期、提交待確認、待審閱與近期成果。
   使用作業／歷史任務選單直接開啟對應五步驟畫面。資料取自本機快取，更新總覽不會自動同步學校。
2. 「課程專頁」彙整指定課程作業、教材、公告、Moodle 評分、附件及歷史成果。
   正式 SIS 成績仍在學習資料中心顯示，不以 Moodle 評分取代正式成績。
3. 「搜尋」支援課程、作業、教材名稱、題目文字及已下載 PDF／DOCX／TXT／CSV 解析內容。
   可篩選課程與作業截止日期；結果附頁／節及原檔下載入口。單／雙字中文也可搜尋。
4. 審閱頁可匯出 Word 或 ZIP。ZIP 包含 PDF、Word、Markdown、已登錄程式／工具產物與 hash 清單；
   原始附件預設不加入，勾選後僅加入建立任務時的輸入快照。DOCX 可獨立產生，不依賴 PDF 成功。
5. 切換步驟、修改需求／節錄／要求／草稿會保存表單；重新開啟恢復適當步驟，或從首頁「繼續上次工作」載入。
   草稿編輯進度與正式任務草稿分開保存；按「保存修改」或審閱匯出後才更新正式草稿與程式檔。
   恢復不自動呼叫 AI，傳送核准與審閱勾選重設；中斷且無草稿時回 AI 設定頁重新確認。

## 資料生命週期與相容性

- 沿用 `study.sqlite3` 的 user-scoped records/events，既有任務、附件與 PDF 不重建。
- 新增 `learning_search` FTS5 trigram 虛擬表；程式啟動以 `CREATE IF NOT EXISTS` 建立。
  索引是可重新建立的衍生資料，原 records schema version 保持 1。
- 新增 records：`search_document`（來源 hash、解析段落與限制）、`preferences/search_index`、
  `preferences/workflow`。全部以本人 user_id 隔離。
- 每次搜尋刷新目前來源清單，重讀已下載檔案驗 hash；相同 hash 重用解析結果。
  已移除作業、教材不再出現在結果；內容異動或 hash 不符時不顯示舊文件節錄。
- 搜尋 SQL 帶 user_id、course_id 條件；FTS 查詢是字面片語，使用參數化查詢。
- 修改草稿撤銷所有已登錄匯出；磁碟舊檔不透過 API 暴露。DOCX／ZIP 下載核對檔案 hash。
- ZIP 依已登錄產物清單建立，不遍歷資料夾；不打包 Cookie、Token、資料庫或未登錄檔案。
